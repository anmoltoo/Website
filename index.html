-- players.luau: who is in this server
local Players = game:GetService("Players")
local Teams = game:GetService("Teams")
local list = Players:GetPlayers()
 
local function teamOf(p)
  if p.Team then return p.Team.Name end
  return "none"
end
 
table.sort(list, function(a, b)
  return a.AccountAge > b.AccountAge
end)
 
for i, p in list do
  print(i, p.Name, teamOf(p), p.AccountAge)
end
 
print("In server:", #list, "of", Players.MaxPlayers)
 
-- run again when someone joins
Players.PlayerAdded:Connect(function(p)
  print("Joined:", p.Name, teamOf(p))
end)
 
Players.PlayerRemoving:Connect(function(p)
  print("Left:", p.Name)
end)

Wyrex External works from outside Roblox

It runs as its own process, reads player positions from memory and draws names, boxes and distance over the game window.

  • Nothing is injected into the Roblox client
  • The overlay draws at your monitor's refresh rate
  • F2 hides the overlay, F3 opens its settings

What people ask before they download.

Email support

Is Wyrex free?

Yes, with a key you renew every 24 hours. Pro drops the key.

Which Windows versions work?

Windows 10 and 11, 64-bit. The installer adds WebView2 if it is missing.

How is the External different?

It reads the game from its own process, so nothing is injected into Roblox.

Can my Roblox account be banned?

Yes. Scripts break the Roblox Terms of Use and any account can be banned. Use one you can lose.

What happens when Roblox updates?

Wyrex pauses until a matching build ships, then updates itself on launch.

Does Wyrex run on Mac or mobile?

No. Wyrex runs on Windows PCs only.
